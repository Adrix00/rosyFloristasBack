# Package Conventions

```
application
    category
    product
    order

domain
    model
    event
    exception
    validation

infrastructure
    web
    persistence
    security
    storage

shared
```

## Application

Each functionality contains:

- command
- query
- dto
- mapper
- port
    - in
    - out
- service

## Domain

The Domain is grouped by business functionality.

Example:

```
model
    category
    product
    order
```

## Infrastructure

Infrastructure is grouped by technical concern.

```
web

persistence

security

mail

storage
```
